## この演習について

4章で学んだ知識(非同期処理、エラーハンドリング、ルーティング、API Routes/Server Actions)を組み合わせて、「ケーキ人気投票ランキング」というミニ機能を作る。

一点、正直に断っておくと、**外部APIを呼び出すという処理は、実は電車・ケーキどちらのプロトタイプにも実例が存在しない**(2つとも、サーバーと一切通信しない自己完結型のゲームだったため)。そのため今回は、4章の頭で確認した実在の`actions.ts`のパターン(早期リターンでのバリデーション、`revalidatePath`)を土台にしつつ、ケーキの世界観に当てはめて新規に組み立てる形になる。

## 一緒にやってみる

この演習はAPI Route・ページ・Server Actionが絡むが、**中身のロジックは普通の関数**。
先にそこだけ書いて確かめる、という順番を小さな例で試しておこう:

```ts
const sortByVotes = (cakes: { name: string; votes: number }[]) =>
  [...cakes].sort((left, right) => right.votes - left.votes);
```

このコードを、**コピペせずに自分の手で入力してみてほしい**。
ここにはNext.jsの要素は何も出てこない。まず並び替えが正しいことだけを確かめる。

<TryIt />

進め方の型を整理すると:

1. **データを扱う関数**(集計・並び替え・更新)を先に書いて、単体で確かめる
2. 次に、それを**API Routeやページから呼ぶ**形に載せる
3. 最後に**Server Action**で更新をつなぐ

Next.js固有の部分でつまずいたときも、「ロジックは合っている」と分かっていれば
配線だけを疑えばよくなる。

## 要件

各項目には「使う知識」として、対応するレッスンへのリンクを付けてある。**リンクは新しいタブで開く**ので、演習ページに書いたコードは消えない。手が止まったら、遠慮なくそのレッスンを開いて読み直してほしい。

### 1. API Route:`/api/cakes/popularity`

`src/app/api/cakes/popularity/route.ts`に、GETリクエストを受けて、以下のようなダミーデータをJSONで返す関数を作成する:

```ts
interface CakePopularity {
  cakeKind: "shortcake" | "chocolate"
  votes: number
}
```

（実際のデータベースは使わず、固定の配列を返すだけでよい。例:`[{ cakeKind: "shortcake", votes: 12 }, { cakeKind: "chocolate", votes: 8 }]`)

使う知識:<a href="/lessons/ch4-07-api-server-actions" target="_blank" rel="noreferrer">4-7 API Routes / Server Actions</a>

### 2. ページルーティング:`/cakes/ranking`

`src/app/cakes/ranking/page.tsx`に、上記のAPI Routeを`fetch`で呼び出し、結果を`.sort()`(3章で学んだ、降順ソート)で並び替えてから、`.map()` + `key`(2章)で一覧表示するページを作成する。`fetch`は`await`を使って結果を待つこと。

`fetch`が失敗する可能性も考え、`try`/`catch`で囲み、失敗した場合は「ランキングを取得できませんでした」という表示を出すこと。

使う知識:<a href="/lessons/ch4-06-nextjs-routing" target="_blank" rel="noreferrer">4-6 Next.jsのルーティング基礎</a>、<a href="/lessons/ch4-03-promise-async-await" target="_blank" rel="noreferrer">4-3 Promiseとasync/await</a>、<a href="/lessons/ch4-04-try-catch" target="_blank" rel="noreferrer">4-4 try/catchとエラーハンドリング</a>、<a href="/lessons/ch3-05-find-some-sort" target="_blank" rel="noreferrer">3-5 .find() / .some() / .sort()</a>、<a href="/lessons/ch2-07-list-rendering-key" target="_blank" rel="noreferrer">2-7 リストレンダリングとkey</a>

### 3. Server Action:`voteForCake`

`"use server"`をつけた`voteForCake(cakeKind: string)`という関数を作成する。`actions.ts`の`updateExerciseStatus`と同じように、以下の早期リターンパターンを踏襲すること:

```ts
const VALID_CAKE_KINDS = ["shortcake", "chocolate"];

export async function voteForCake(cakeKind: string) {
  if (!VALID_CAKE_KINDS.includes(cakeKind)) {
    return; // 不正な値なら、何もせず処理を終える
  }

  // (実際の投票処理はダミーでよい。console.logで代用してもよい)

  revalidatePath("/cakes/ranking");
}
```

使う知識:<a href="/lessons/ch4-07-api-server-actions" target="_blank" rel="noreferrer">4-7 API Routes / Server Actions</a>

## クリア条件

- API Routeが正しくJSONを返すこと
- `/cakes/ranking`ページが、`fetch` + `await`でAPIを呼び出し、結果を一覧表示すること
- `fetch`の失敗が`try`/`catch`でハンドリングされていること
- `voteForCake`が、`actions.ts`と同じ早期リターンのパターンでバリデーションを行っていること
- `revalidatePath`が正しく呼ばれていること
