```css
:root {
  --accent-color: #ef6c00;
}

.highlight {
  color: var(--accent-color);
}

.highlight:hover {
  font-weight: 700;
}
```

**ポイント**

- **`:root` はページ全体を指すセレクタ**(実質 `<html>` 要素)。ここに変数を置くと、ページのどこからでも `var()` で参照できます。
- **CSS変数の名前は `--` で始める**決まりです。`-accent-color` のようにハイフン1つでは変数になりません。
- **`var(--accent-color)` は「その変数の値に置き換える」**という意味。色を変えたくなったら `:root` の1か所を直すだけで、参照しているすべての場所に反映されます。
- **`:hover` は擬似クラス**で、「マウスが乗っているあいだだけ」という条件を足すもの。`.highlight:hover` のように、間にスペースを入れず続けて書きます(スペースを入れると「`.highlight` の子孫要素のうちホバー中のもの」という別の意味になります)。
