## このレッスンについて

HTML自体はすでにある程度学習済みとのことなので、このレッスンは「もう知ってるか」を自己診断して、知っていればすぐスキップしていい、という位置づけにする。以下の質問に全部「知ってる」と答えられるなら、次のレッスン(CSSセレクタの基本)に進んで問題ない。

## 診断チェック

- `<div>`, `<p>`, `<button>`, `<input>`, `<ul>`/`<li>`の役割を説明できる
- 属性(`class="..."`, `id="..."`)の意味が分かる
- 親要素・子要素・ネスト(入れ子構造)の概念が分かる

## 簡単な説明(念のため)

HTMLは、画面に表示する要素の"種類"と"構造"を表すマークアップ言語。

```html
<div class="card">
  <h2>タイトル</h2>
  <p>本文</p>
  <button>押す</button>
</div>
```

- `<div>` — 特に意味を持たない、汎用的な箱(グループ化に使う)
- `<h1>`〜`<h6>` — 見出し(数字が小さいほど大きい見出し)
- `<p>` — 段落(文章のまとまり)
- `<button>` — ボタン
- `<ul>`/`<li>` — リスト(`ul`が全体、`li`が1項目)

`class="card"`のような属性は、その要素に「名前」や「追加情報」をつけるためのもの。特に`class`は、次のレッスン以降で扱うCSSから、その要素を指定するための目印として使われる。

## 実際のプロトタイプでの例

Cake-Gameの`App.tsx`では、JSX(2章で学んだ通り、HTMLに似た構文)の中で、`className`(JSX版の`class`)がひたすら使われてる:

```tsx
<section className="cake-selector" aria-label="販売するケーキ">
  <div className="cake-selector__header">
    <h2>ケーキ</h2>
  </div>
</section>
```

`aria-label`のような属性は、アクセシビリティ(スクリーンリーダーなどの支援技術に、要素の意味を伝えるための情報)のためのもの。これも本格的なHTML/JSXでは頻出する。
