```css
.profile-card {
  background: #ffffff;
  border-radius: 12px;
  box-shadow: 0 2px 6px rgba(0, 0, 0, 0.1);
  font-weight: 600;
}
```

**ポイント**

- **`box-shadow` は「横のずれ 縦のずれ ぼかし 色」の順**。`0 2px 6px` は「横にはずらさず、下に2px、6pxぼかす」という意味です。影は真下に少しだけ落とすと自然に見えます。
- **影の色は `rgba()` で薄くする**のが定番。`rgba(0, 0, 0, 0.1)` は「黒の10%」で、背景の色を選ばず馴染みます。`#000000` のような不透明な黒にすると、一気に重たい見た目になります。
- **`font-weight` は子要素にも受け継がれます**。`.profile-card` に指定すれば、中の `<p>` もまとめて太字になります(このように親から子へ引き継がれる性質を「継承」と呼びます)。
- 余白(`padding`)を足すともっとカードらしくなります。クリア条件には含まれないので、余裕があれば試してみてください。
