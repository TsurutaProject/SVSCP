```html
<div>
  <h2>のりまき</h2>
  <p>ゲームを作るのが好きです。よろしくお願いします。</p>
  <button>フォローする</button>
</div>
```

**ポイント**

- **`<h2>` は見出し、`<p>` は段落、`<button>` はボタン**。見た目ではなく「その中身が何であるか」でタグを選びます。文字を大きくしたいから `<h2>` にする、という選び方はしません(大きさはCSSで決めます)。
- **ネスト(入れ子)は開始タグと終了タグの対応で決まります**。`<div>` の中に3つの要素が並んでいるので、`<div>` の終了タグ `</div>` は3つすべてより後ろに来ます。
- 見出しは `<h1>`〜`<h6>` まであり、数字が小さいほど上位です。ページ内にすでに `<h1>` がある想定なので、カードの見出しは `<h2>` にしています。
