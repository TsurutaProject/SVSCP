```css
.dashboard {
  display: grid;
  grid-template-columns: minmax(200px, 250px) 1fr;
}
```

**ポイント**

- **`grid-template-columns` は「列の幅を、左から順に並べて書く」**もの。値が2つあるので2カラムになります。行数は中身の数から自動で決まります。
- **`minmax(200px, 250px)` は「200pxより狭くならず、250pxより広くならない」**という指定。サイドバーのように「だいたい固定幅だけど、少しは伸び縮みしてほしい」列にちょうど合います。
- **`1fr` は「残りの幅を全部」**という意味。`fr` はグリッド専用の単位で、`%` と違って gap を差し引いた残りを配ってくれるので、はみ出す心配がありません。
- 子要素の側には何も書いていない点に注目してください。**どこに何が入るかは、親の列指定とHTMLの並び順だけで決まります**。
- Flexboxとの使い分けは、**1方向に並べるだけならFlex、行と列の両方を揃えたいならGrid**、と考えると迷いにくいです。
