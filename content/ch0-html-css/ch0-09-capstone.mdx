## この演習について

ch0で学んだ内容(セレクタ、CSS変数、余白とサイズ、Flexbox、position、`@keyframes`)を全部使って、Cake-Gameの実際のスコアボードを、HTML+CSSだけで再現する。JS/TSは一切使わない、純粋なHTML/CSSの総仕上げ。

## 完成イメージ

横に並んだ複数のスコアカード(「得点」「コンボ」など)があり、それぞれのカードには軽い影と角丸がついている。カードの右下には、コンボ数を示す小さなバッジが重ねて表示され、ページ読み込み時に軽く弾むアニメーションをする。

## 一緒にやってみる

要件が5つ並ぶと「どこから手を付けるか」で止まりやすい。
**まず全部の枠を置いて、色や余白は後から足す**という順番を、小さな例で試しておこう:

```css
.panel {
  display: flex;
  gap: 12px;
}
```

このコードを、**コピペせずに自分の手で入力してみてほしい**。
まだ色も影も付けない。「並びだけ合っている状態」をいったん作るのが目的。
それができたら、`background`や`border-radius`を1つずつ足していこう。

<TryIt />

進め方の型を整理すると:

1. **まずレイアウト**(`display: flex` / `grid`、`gap`)で、位置関係だけ合わせる
2. 次に**大きさと余白**(`padding`、`width`)
3. 最後に**見た目**(`background`、`border-radius`、`box-shadow`、アニメーション)

この順番だと、途中でも「どこまでできたか」が目で分かる。
逆に色から先に付けると、並びを直すたびに作り直しになりやすい。

## 要件

各項目には「使う知識」として、対応するレッスンへのリンクを付けてある。**リンクは新しいタブで開く**ので、演習ページに書いたコードは消えない。手が止まったら、遠慮なくそのレッスンを開いて読み直してほしい。

### 1. CSS変数の定義

`:root`に、以下のCSS変数を定義する:

```css
:root {
  --card-bg: rgba(255, 255, 255, 0.88);
  --card-border: rgba(112, 83, 70, 0.14);
  --accent-color: #ef6c00;
}
```

使う知識:<a href="/lessons/ch0-02-selectors-and-variables" target="_blank" rel="noreferrer">0-2 CSSセレクタの基本とCSS変数</a>

### 2. スコアボード全体のレイアウト(Flexbox)

```html
<div class="score-board">
  <div class="score-card">得点: 120</div>
  <div class="score-card">コンボ: 3</div>
</div>
```

`.score-board`に、実際のCake-Gameと同じく`display: flex`と`gap: 10px`を指定する。

使う知識:<a href="/lessons/ch0-05-flexbox" target="_blank" rel="noreferrer">0-5 Flexboxでレイアウトを組む</a>、<a href="/lessons/ch0-04-spacing-and-sizing" target="_blank" rel="noreferrer">0-4 余白とサイズ</a>

### 3. 各カードの見た目(余白とサイズ、見た目を整える)

`.score-card`に、以下を指定する(実際のCake-Gameの値を参考にしてよい):

- `padding: 10px 12px`
- `border: 2px solid var(--card-border)`
- `border-radius: 8px`
- `background: var(--card-bg)`
- `box-shadow: 0 12px 24px rgba(80, 48, 32, 0.08)`
- `min-width: 96px`

使う知識:<a href="/lessons/ch0-03-visual-styling" target="_blank" rel="noreferrer">0-3 見た目を整える</a>、<a href="/lessons/ch0-04-spacing-and-sizing" target="_blank" rel="noreferrer">0-4 余白とサイズ</a>

### 4. コンボバッジの重ね配置(position)

`.score-card`に`position: relative`を指定し、その中に`.combo-badge`という子要素を追加する:

```html
<div class="score-card">
  コンボ: 3
  <span class="combo-badge">🔥</span>
</div>
```

`.combo-badge`は`position: absolute`で、カードの右下(`right: 9px; bottom: 9px;`)に配置する。

使う知識:<a href="/lessons/ch0-07-position" target="_blank" rel="noreferrer">0-7 positionでの重ね配置</a>

### 5. 弾むアニメーション(@keyframes)

`combo-pop`という名前の`@keyframes`を定義し(0-8で作ったものを再利用してよい)、`.combo-badge`に適用する。

使う知識:<a href="/lessons/ch0-08-keyframes" target="_blank" rel="noreferrer">0-8 @keyframesでアニメーション</a>

## クリア条件

- CSS変数が`:root`で定義され、`var()`で正しく使われていること
- `.score-board`がFlexboxで横並びになっていること
- 各カードに、影・角丸・背景色が正しく指定されていること
- `.combo-badge`が、親カードの右下に`position: absolute`で正しく重ねて配置されていること
- ページを開いた瞬間、バッジが軽く弾むアニメーションをすること
