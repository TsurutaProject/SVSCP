## 説明

JavaScriptで関数を書く方法は複数あるけど、モダンな書き方としてよく使われるのが**アロー関数**。

```js
// 従来のfunction文
function add(a, b) {
  return a + b;
}

// アロー関数
const add = (a, b) => {
  return a + b;
};
```

`function`というキーワードを使わず、引数リストの後に`=>`(矢印)を書いて、その後に処理を書く形。

さらに、**処理が「値を1つ返すだけ」の場合は、`{}`と`return`を省略して1行で書ける**:

```js
const add = (a, b) => a + b;
```

これを**暗黙のreturn(implicit return)** と呼ぶ。`{}`をつけずに書いた場合、`=>`の右側の式がそのまま戻り値になる。

## 実際のプロトタイプでの例

Cake-Gameの`utils/cakeGeometry.ts`に、まさにこの「1行で書くアロー関数」の実例がある:

```ts
export const normalizeAngle = (angle: number): number => ((angle % 360) + 360) % 360
```

これは「角度(度数)を0〜360度の範囲に収める」関数。`{}`も`return`もなく、`=>`の右側の計算結果がそのまま返る形になってる。TypeScriptなので引数と戻り値に型がついてるけど、アロー関数の基本構造自体は最初の例と同じ。

## コラム:Java・Rubyとの対応

### Java(関数型インターフェース、`BinaryOperator`とか触ってたなら特に馴染みあるはず)

```java
BinaryOperator<Integer> add = (a, b) -> a + b;
```

JavaのラムダT式は`->`(矢印1本)、JSは`=>`(イコール+不等号)で見た目は微妙に違うけど、**「引数リスト → 処理」という構造自体はほぼ同じ**。Javaでラムダ式を書いたことがあるなら、アロー関数はほぼ「見た目が変わっただけ」に近い感覚で読めるはず。

違いとしては、Javaは`BinaryOperator<Integer>`のように**関数の型(関数型インターフェース)を事前に定義しておく**必要があるのに対して、JS/TSは`(a: number, b: number) => number`のように**その場で関数の型を直接書ける**。TypeScriptの方が身軽な感じ。

### Ruby(ブロック・Proc・ラムダ)

```ruby
add = ->(a, b) { a + b }
# または
add = lambda { |a, b| a + b }
```

Rubyの`->(a, b) { ... }`という書き方(通称「stabby lambda(スタビーラムダ)」)は、見た目の雰囲気がアロー関数にかなり近い。`->`という矢印っぽい記号を使うところも共通してる。

ただしRubyには「ブロック」という別の概念(`each do |x| ... end`とか`{ |x| ... }`)もあって、これはJSのアロー関数とは思想が違う(ブロックは関数というより「処理の塊を渡す」仕組み)。ここは無理に対応させようとせず、**「Rubyのラムダに近いもの」くらいの理解で十分**。

### まとめると

| 言語 | 書き方 | 矢印 |
|---|---|---|
| JavaScript/TS | `(a, b) => a + b` | `=>` |
| Java | `(a, b) -> a + b` | `->` |
| Ruby | `->(a, b) { a + b }` | `->` |

3つとも「引数 → 処理」という構造は共通してるから、「見た目のクセが違うだけで、考え方はもう知ってる」という感覚で入れるはず。

## 一緒にやってみる

まず、簡単な例で実際に手を動かしてみよう。「2つの数値を足し算する」`add`関数を、アロー関数で書くとこうなる:

```ts
const add = (a: number, b: number): number => a + b;
```

このコードを、**そのまま自分の手で1文字ずつ入力してみてほしい**(コピペではなく)。入力できたら、下の行も追加して、実行結果を確認してみよう:

```ts
console.log(add(2, 3)); // 5と表示されるはず
```

ここでの書き方の型を整理すると:

```
const 関数名 = (引数1: 型, 引数2: 型): 戻り値の型 => 計算式;
```

- `const 関数名 =` — 変数として、関数に名前をつける
- `(引数1: 型, ...)` — 受け取る値と、その型
- `: 戻り値の型` — この関数が最終的に返す値の型
- `=>` の右側 — 実際の計算・処理。1行で済む場合は、これがそのまま戻り値になる(暗黙のreturn)

この型に当てはめれば、次の演習も同じ手順で書けるはず。**「何から書けばいいか分からない」時は、まずこの`const 関数名 = (引数: 型): 戻り値の型 => ...`という骨組みだけ先に書いて、それから中身を埋めていく**、という順番で進めるとやりやすい。
