## 説明

文字列の中に変数の値を埋め込みたいとき、従来は`+`で連結してた:

```js
const name = "のりまき";
const message = "こんにちは、" + name + "さん";
```

**テンプレートリテラル**を使うと、バッククォート(`` ` ``)で囲んで、`${}`の中に変数や式を書くだけで済む:

```js
const message = `こんにちは、${name}さん`;
```

`${}`の中には変数だけでなく、計算式や関数呼び出しなど、どんな式でも書ける:

```js
const price = 100;
const message = `合計:${price * 2}円`;
// "合計:200円"
```

複数行の文字列もそのまま改行して書けるのも地味に便利:

```js
const message = `1行目
2行目`;
```

## 実際のプロトタイプでの例

Train_Proto-Typeの`App.jsx`から、一番シンプルな例:

```js
setMessage(`高速レールは${currentStage.maxFastRails}本までです。`)
```

これは「`currentStage.maxFastRails`(その面での高速レールの上限本数)を埋め込んだ注意メッセージを表示する」処理。`+`で書くよりずっと読みやすい。

もう少し複雑な例だと、`${}`の中に三項演算子(条件分岐の式)を埋め込んでるケースもある:

```js
return `${seconds}秒${stageResult.difference > 0 ? '早く' : 'ゆっくり'}できそう`
```

これは「差分がプラスなら『早く』、マイナスなら『ゆっくり』」という文言を、テンプレートリテラルの中で出し分けてる。`${}`の中身は単なる変数じゃなくて式なので、こういう条件分岐もそのまま書ける。

さらに、ReactのCSSクラス名を動的に組み立てるのにもよく使われてる:

```js
className={`rail-piece rail-piece-${type} rail-piece-${railAsset.shape} ${compact ? 'rail-piece-compact' : ''}`}
```

これは「基本のクラス名+種類ごとのクラス名+条件付きでcompact用クラス名」を1行で組み立てるパターン。2章(React基礎)でも頻出するので、ここで感覚を掴んでおくと後が楽になる。

## コラム:Java・Rubyとの対応

### Java(テキストブロック/文字列フォーマット)

```java
String message = "こんにちは、" + name + "さん";
// または String.format
String message = String.format("こんにちは、%sさん", name);
```

Javaには`${}`のような埋め込み構文は標準では長らくなかった(Java 21以降のテキストブロックでも、埋め込みは別途`String.format`頼み)。`+`連結か`String.format`の`%s`のようなプレースホルダー方式に慣れてるなら、テンプレートリテラルの`${}`はそれよりだいぶ直感的に感じられるはず。

### Ruby

```ruby
message = "こんにちは、#{name}さん"
```

Rubyの文字列展開(`#{}`)は、JSのテンプレートリテラル(`${}`)と発想がほぼ同じ。違いは記号が`#`か`$`か、ダブルクォート`"`かバッククォート`` ` ``かくらい。Rubyを触ってたなら、この構文は一番すんなり入ってくるはず。
