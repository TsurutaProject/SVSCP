## 説明

**分割代入(destructuring)**は、配列やオブジェクトから値を取り出して、個別の変数に一気に代入する書き方。

```js
// 配列の分割代入
const [first, second] = [10, 20];
// first = 10, second = 20

// オブジェクトの分割代入
const { name, age } = { name: "のりまき", age: 20 };
// name = "のりまき", age = 20
```

**スプレッド構文(`...`)**は、配列やオブジェクトの中身を「展開」する書き方。主に2つの使い道がある:

```js
// 1. 配列・オブジェクトのコピー、結合
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]

const obj1 = { a: 1 };
const obj2 = { ...obj1, b: 2 }; // { a: 1, b: 2 }

// 2. 関数の引数を可変長で受け取る(rest構文、書き方は同じ...)
function sum(...numbers) {
  return numbers.reduce((total, n) => total + n, 0);
}
```

## 実際のプロトタイプでの例

Cake-Gameでは、状態更新のときにスプレッド構文が頻出する。典型的なパターン:

```ts
setOrder({ ...activeOrder, status: "completed" })
```

これは「既存の`activeOrder`オブジェクトの中身を全部コピーしつつ、`status`だけ`"completed"`に上書きした新しいオブジェクトを作る」という意味。Reactでは**既存のオブジェクトを直接書き換えず、新しいオブジェクトを作って置き換える**のが基本ルールだから、この「コピーしつつ一部だけ変える」パターンが至るところで出てくる。

## コラム:Java・Rubyとの対応

### Java

Javaに「分割代入」に相当するものは実は薄い。レコード(Record)を使えば近いことはできるけど、`(a, b) = someArray`のような書き方はない。強いて言うなら、複数の値を1個ずつ変数に取り出す操作自体は、Javaだと素直に`arr[0]`, `arr[1]`と書くしかない。ここはJS/TSの方が便利な部分。

### Ruby

Rubyは実はJS以上に分割代入(多重代入)が柔軟:

```ruby
first, second = [10, 20]
name, age = "のりまき", 20
```

`*`を使ったスプレッド的な書き方(splat演算子)もある:

```ruby
first, *rest = [1, 2, 3, 4]
# first = 1, rest = [2, 3, 4]
```

Rubyを触ってたなら、この辺の感覚はむしろJSよりRubyの方が馴染み深いかもしれない。JSのスプレッド`...`とRubyの`*`は、記号は違うけど「残りを全部まとめて受け取る」という発想は同じ。

## 演習

`{ name: "のりまき", score: 80 }`というオブジェクトを受け取って、`score`だけを`100`に上書きした新しいオブジェクトを返す関数を、スプレッド構文を使って書いてください。

### クリア条件

- 元のオブジェクトを直接書き換えていないこと(新しいオブジェクトを返している)
- スプレッド構文(`...`)を使っていること
- `{ name: "のりまき", score: 100 }`が返ること
